# Study resources

Follow the resources in roadmap order. Choose **one main course or guide per stage** and build alongside it. These links point to the original providers; access details and course content can change, so check each provider’s site.

## Tools and workflow

- [GitHub Learn](https://learn.github.com/) — self-directed courses and hands-on practice for using GitHub.
- [GitHub Skills](https://skills.github.com/) — interactive exercises for practicing GitHub basics.
- [Google Colab](https://colab.research.google.com/) — browser notebooks when you are not ready to install Python packages locally.

## Python

**Main resource:** [CS50’s Introduction to Programming with Python](https://cs50.harvard.edu/python/) — starts with functions and variables, then covers conditions, loops, exceptions, libraries, tests, file I/O, and classes. Designed for learners with or without prior programming experience.

**Reference:** [Python Tutorial](https://docs.python.org/3/tutorial/) — useful for looking up language features after you have begun coding.

## Math and data

- [Khan Academy Math](https://www.khanacademy.org/math) — review algebra, equations, functions, and graphs.
- [Khan Academy Statistics and Probability](https://www.khanacademy.org/computing/statistics-probability) — practice describing data, probability, sampling, and inference.
- [3Blue1Brown: Essence of Linear Algebra](https://www.3blue1brown.com/topics/linear-algebra) — visual intuition for vectors and matrices.
- [NumPy Learn](https://numpy.org/learn/) — arrays and numerical computing in Python.
- [pandas Getting Started](https://pandas.pydata.org/docs/getting_started/index.html) — loading, exploring, and working with tabular data.
- [Matplotlib Tutorials](https://matplotlib.org/stable/tutorials/index.html) — plotting data.

Do not pause the roadmap to complete all of math. Learn the relevant concept when it first appears, then return for more depth as needed.

## AI foundations

- [CS50’s Introduction to Artificial Intelligence with Python](https://cs50.harvard.edu/ai/) — search, knowledge, uncertainty, optimization, learning, neural networks, and language. Use this as an optional deeper companion after learning Python basics; you do not need to finish the entire course to continue.

## Machine learning

**Main resource:** [Google’s Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course) — lessons and hands-on exercises covering core machine learning ideas.

**Practice and reference:** [scikit-learn Getting Started](https://scikit-learn.org/stable/getting_started.html) — see the basic workflow for fitting, predicting, preprocessing, pipelines, and evaluation.

## Deep learning

**Main resource:** [PyTorch Tutorials](https://docs.pytorch.org/tutorials/) — begin with Learn the Basics to follow a complete small model workflow.

## Generative AI and LLMs

**Main resource:** [Hugging Face LLM Course](https://huggingface.co/learn/llm-course) — covers transformer models, working with pretrained models, datasets, tokenizers, and sharing demos.

Use a small model or hosted notebook for learning. Training a modern production-scale language model from scratch is outside this beginner path.

## How to use a resource well

1. Write down the question you want the lesson to answer.
2. Work through the example yourself before reading the solution.
3. Change one thing and observe how the result changes.
4. Save a short note and a link to your code in [PROGRESS.md](PROGRESS.md).
5. If a lesson is confusing, try a second explanation for that topic; do not restart the entire course.
