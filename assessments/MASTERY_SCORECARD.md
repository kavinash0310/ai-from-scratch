# 100-point AI/ML mastery scorecard

Use this scorecard after completing the labs and projects. It scores demonstrated skills, not pages read. Save links to code, reports, and explanations as evidence. A learner may score highly in one specialty without knowing every branch of AI.

## Scoring

For each row, assign:
- **0% of row points:** cannot explain or perform the task yet.
- **25%:** recognizes terms but cannot do it without copying.
- **50%:** completes a guided version, but misses assumptions or evaluation.
- **75%:** works independently and explains the main tradeoffs.
- **100%:** works independently, checks edge cases/failures, and can teach the idea with evidence.

| Competency | Points | Evidence required |
| --- | ---: | --- |
| Programming and tooling | 10 | Write readable Python functions, manage files/errors, use Git, and reproduce an environment |
| Mathematics and numerical reasoning | 10 | Explain vector/matrix shapes, probability, derivatives, gradients, and one update by hand |
| Classical AI and problem formulation | 8 | Define a search problem and implement BFS/A* or a small constraint solver with assumptions |
| Data and ML workflow | 12 | Frame target/features/prediction time, detect leakage, build baseline, fit and compare models |
| Evaluation and uncertainty | 12 | Choose metrics from error costs, use valid splits, inspect errors, calibration, and subgroup/slice behavior |
| Deep-learning implementation | 10 | Trace forward/loss/backward/update; implement or adapt a small network and diagnose learning curves |
| NLP, LLMs, and generative systems | 12 | Explain tokenization/attention/inference; build a retrieval or language workflow and evaluate evidence/failures |
| One specialization | 8 | Complete a relevant project with a suitable specialty-specific baseline and evaluation |
| Engineering and responsible practice | 8 | Version artifacts, monitor service/data/model behavior, document privacy/security/limitations, define rollback |
| Research and communication | 10 | Read a paper critically, reproduce a small result or ablation, present evidence and caveats |
| **Total** | **100** | |

## Gates

A score total can hide a serious weakness. Before claiming a complete AI/ML foundation, also meet all gates:

1. At least **70/100** overall.
2. At least **half the points** in programming, ML workflow, and evaluation.
3. At least **four finished project artifacts**, including one ML model and one system or specialization project.
4. Every finished project includes a baseline, realistic evaluation, error analysis, and limitations.
5. Explain one successful and one failed experiment without relying on a model-generated summary.

For a 90+ score, ask a peer or mentor to review a project report and reproduce a result. The final 100 points are evidence of this rubric's coverage, not proof of professional expertise or readiness for high-impact deployment. Continue learning from papers, new data, code review, and real users.
