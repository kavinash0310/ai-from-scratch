## Welcome

This repository is your step-by-step learning workspace. It is designed for a complete beginner: no programming experience, advanced math, paid course, or powerful computer is required to begin.

The full path takes about **7–9 months at 6–8 focused hours a week**. Treat the timeline as a guide, not a deadline. It is normal to spend longer on a stage.

## The learning path

| Stage | You will learn | You will make |
| --- | --- | --- |
| 0. Setup | How to study, use notebooks, and save your work | Your learning log |
| 1. Python | Programming basics, problem solving, files, and debugging | A small useful Python program |
| 2. Math and data | Statistics, probability, vectors, and data exploration | A data analysis |
| 3. AI foundations | Search, decisions, and how AI problems are framed | A path-finding or game-playing program |
| 4. Machine learning | Data, baselines, training, evaluation, and model selection | A tested prediction model |
| 5. Deep learning | Neural networks, tensors, training loops, and GPUs | An image or text classifier |
| 6. Choose a specialty | Computer vision, language, recommendations, time series, or reinforcement learning | A focused project |
| 7. Generative AI | Transformers, embeddings, retrieval, and model evaluation | A document question-answering app |
| 8. Ship responsibly | Interfaces, deployment, monitoring, privacy, and limitations | A documented capstone |

## What you need before starting

- A computer with internet access. A browser notebook is enough at first.
- Basic arithmetic and a willingness to practice. Learn the needed math as it appears.
- A regular study slot. Even 30–60 minutes most days can add up.
- Patience with errors. Debugging is a normal part of programming.

You do **not** need calculus, a computer science degree, a paid API, or a GPU to start. Use hosted notebooks for heavier exercises when needed.

## How to use this repository

1. Read the [roadmap](ROADMAP.md) once to see the whole journey.
2. Begin with Stage 0 and work in order. Do not skip the projects.
3. Use one main resource per topic from [RESOURCES.md](RESOURCES.md); avoid collecting courses instead of practicing.
4. Put your notes and project links in [PROGRESS.md](PROGRESS.md).
5. For every project, explain the problem, data, baseline, evaluation, and limitations. The [project template](templates/project-template.md) gives you a starting point.

A useful weekly rhythm is: learn one concept, code it yourself, change something, and write down what you learned. Try to spend more time practicing than watching.

## Use AI as a tutor

AI tools can help explain an error, give a hint, or quiz you. First make an attempt yourself. Ask for the smallest hint that helps you continue, then verify the explanation by running code or checking a trusted source. Do not submit generated code you cannot explain.

## What “from scratch” means here

You will learn how the pieces work and implement small algorithms yourself. You will also use established libraries and pretrained models for realistic projects. Training a modern large language model from zero requires enormous datasets and computing resources; it is not a beginner prerequisite.
