# AI/ML project ladder

Use projects to prove you can apply a topic, not just recognize its vocabulary. Each project has a clear question, staged milestones, deliverables, limitations, and a shared 100-point rubric. Do them in order or select a specialty after Project 2.

| Project | Stage | Main evidence |
| --- | --- | --- |
| [01 — Data investigation](01-data-investigation.md) | Beginner | Clean data, answer a question, document a reproducible analysis |
| [02 — Tabular ML](02-tabular-ml.md) | Beginner/intermediate | Compare baselines and models with a valid split and error analysis |
| [03 — Image classifier](03-image-classifier.md) | Intermediate | Train or fine-tune a vision model and analyze per-class behavior |
| [04 — Text classification and search](04-text-and-search.md) | Intermediate | Compare lexical and embedding methods with retrieval/classification metrics |
| [05 — Grounded document assistant](05-grounded-assistant.md) | Intermediate/advanced | Build retrieval, citation checks, abstention, and security evaluation |
| [06 — Specialization capstone](06-specialization-capstone.md) | Advanced | Complete a reproducible project in one chosen AI specialty |

## Suggested rhythm

Spend a session on each milestone. Commit code and notes in small steps. Keep a record of experiments that fail; an honest failure analysis is valuable evidence. Before using personal or consequential data, check permission, privacy, and potential harm.

Score projects using the [shared rubric](RUBRIC.md). Reach at least 70/100 before adding complexity. A score below that means improve the problem definition, baseline, or evaluation before changing to a larger model.

These projects build practical competence; no project score alone proves expertise. Use the [mastery checks](../assessments/MASTERY_CHECKS.md) and [100-point course scorecard](../assessments/MASTERY_SCORECARD.md) as separate checkpoints.
