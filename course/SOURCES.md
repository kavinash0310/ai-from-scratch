# Course sources and research trail

This course combines original course materials, official library documentation, textbooks, and primary research papers. Use sources in the chapter order; do not try to read everything at once. Course contents and software APIs can change, so check the provider's current version.

## Programming and computing

- [Harvard CS50’s Introduction to Programming with Python](https://cs50.harvard.edu/python/) — beginner Python syllabus, exercises, debugging, files, and libraries.
- [Python Tutorial](https://docs.python.org/3/tutorial/) — language reference and tutorial.
- [GitHub Learn](https://learn.github.com/) — GitHub and version-control practice.

## Math, data, and machine learning

- [Khan Academy Mathematics](https://www.khanacademy.org/math) — arithmetic, algebra, functions, statistics, and probability review.
- [3Blue1Brown linear algebra series](https://www.3blue1brown.com/topics/linear-algebra) — geometric intuition for vectors and matrices.
- [NumPy Learn](https://numpy.org/learn/) — arrays and numerical computing.
- [pandas Getting Started](https://pandas.pydata.org/docs/getting_started/index.html) — tabular data workflows.
- [Google Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course) — linear and logistic regression, classification metrics, data, generalization, neural networks, embeddings, LLM introductions, production, and fairness.
- [scikit-learn Getting Started](https://scikit-learn.org/stable/getting_started.html) — estimators, preprocessing, pipelines, fitting, and evaluation.

## Deep learning, NLP, and LLMs

- [PyTorch Tutorials](https://docs.pytorch.org/tutorials/) — beginner workflow plus advanced model and performance topics.
- [Dive into Deep Learning](https://d2l.ai/) — interactive text with math, code, and discussion.
- [Deep Learning](https://www.deeplearningbook.org/) by Goodfellow, Bengio, and Courville — textbook reference.
- [Hugging Face LLM Course](https://huggingface.co/learn/llm-course) — transformers, inference, fine-tuning, datasets, tokenizers, and demos.

## Primary papers

- Vaswani et al., [Attention Is All You Need](https://arxiv.org/abs/1706.03762) — transformer architecture.
- Devlin et al., [BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding](https://arxiv.org/abs/1810.04805) — bidirectional representation learning.
- Lewis et al., [Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks](https://arxiv.org/abs/2005.11401) — parametric and retrieved knowledge.
- Hu et al., [LoRA: Low-Rank Adaptation of Large Language Models](https://arxiv.org/abs/2106.09685) — parameter-efficient adaptation.
- He et al., [Deep Residual Learning for Image Recognition](https://arxiv.org/abs/1512.03385) — residual networks.
- Ho et al., [Denoising Diffusion Probabilistic Models](https://arxiv.org/abs/2006.11239) — diffusion-based generation.

## Engineering and responsibility

- [Google’s Rules of Machine Learning](https://developers.google.com/machine-learning/guides/rules-of-ml) — engineering practices for ML projects.
- [NIST AI Risk Management Framework resources](https://www.nist.gov/itl/ai-risk-management-framework/ai-risk-management-framework-resources) — risk and governance guidance. The framework is being updated; check the current version before relying on it.

## How to use sources

1. Start with the course chapter and its plain-language explanation.
2. Use official documentation to learn the library interface.
3. Read a primary paper only after you understand the problem it addresses.
4. Record the version and date for resources that change.
5. Cross-check claims that affect safety, legal compliance, or significant decisions.
