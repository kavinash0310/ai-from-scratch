# The AI From Scratch textbook

This index links the course's long-form subject volumes. The intended reader may be new to programming and AI. Read in order, work through each example, define unfamiliar terms in your own words, and complete the practice questions before moving on. The lesson files provide a guided chapter sequence; labs and projects turn the ideas into working systems.

## How to use each volume

1. Read once for the main idea and mark unfamiliar terms.
2. Rework the examples by hand, then reproduce them in code where possible.
3. Answer the review questions without looking back.
4. Complete a lab or small project and explain its assumptions.
5. Inspect errors and write down one limitation and one safe use case.
6. Revisit the mastery checks and return to uncertain sections.
